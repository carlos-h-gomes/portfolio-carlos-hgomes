Case study 02 · Workflow visualization

Turning bot knowledge bases into visual system maps

I replaced a manual Figma diagramming process with a pipeline that exports bot knowledge bases, interprets their structure, and renders navigable React Flow diagrams.

  • n8n
  • JSON
  • React

The challenge

Documentation was accurate only until the bot changed again.

Specialists manually recreated bot knowledge bases in Figma, article by article and block by block. A large base could contain more than 1,400 articles and 10 to 30 blocks per article. The work could consume most of a month, and later changes required the diagram to be updated manually again.

What I owned

A source-driven pipeline instead of a drawing exercise.

  • Mapped the exported JSON structure and the relationships required for a readable flow.
  • Built the transformation from articles and blocks into nodes and edges.
  • Created the visual layer in React Flow so specialists could navigate large structures.
  • Used workflow orchestration to make exports and updates repeatable.
  • Included variables and block types so the diagram carried operational context, not just shape.

Architecture

The bot remains the source of truth.

Bot knowledge baseArticles, blocks, variables, and navigation relationships
JSON exportStructured snapshot produced through an automated workflow
Python transformNormalization into graph nodes, edges, labels, and metadata
React FlowNavigable visual map for analysis and customer documentation

Key decisions

Generate documentation from structure, not screenshots.

  • JSON as the handoffPreserved the bot's hierarchy and made the transformation deterministic.
  • Graph-based renderingMatched the mental model of navigation flows better than static pages.
  • Metadata in the nodesMade variables and block types visible to the people maintaining the system.
  • Repeatable updatesAllowed the same pipeline to regenerate diagrams when the source changed.

Outcome

A reusable internal product replaced a month-long manual process.

For the largest knowledge bases, the end-to-end process moved from up to 30 days of manual diagramming to approximately eight hours of automated processing. At least 40 flows now follow this pattern, and updates can be regenerated from the exported source instead of redrawn.
