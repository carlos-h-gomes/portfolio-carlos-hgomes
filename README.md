# Carlos Henrique Gomes — Portfolio

Personal portfolio focused on AI automation, systems integration, backend services, data workflows, and solutions engineering.

## Languages

- English: `index.html`
- Português: `pt/index.html`

Both versions include three evidence-led case studies, matching PDF resumes, technical stack, education, ProcessSurge product work, and Carlinhos — a local, deterministic portfolio assistant that does not call an external AI service.

## Selected evidence

- 30+ customers currently using an internal analytics platform.
- 40+ bot flows converted into automated visual maps.
- 100+ monthly contract renewals handled through automation.
- Approximately 35 internal APIs built to reduce external dependencies.

Company and customer details are intentionally anonymized. Published outcomes are conservative and grounded in production work.
